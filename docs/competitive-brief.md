# Brief Competitivo — TrustCore vs. Holded / Quipu / Sage / Sesame

## Resumen ejecutivo
Holded y Quipu dominan el segmento SaaS de facturación+gestión en España, con sitios web profesionales, mega-menús por sector, pricing transparente 3-tiers, y blogs editoriales fuertes. TrustCore compite por nicho diferenciado: **suite unificada VeriFactu + Control Horario + IPSI (Ceuta/Melilla)** con positioning de *compliance-first*. Nuestro gap web es de forma, no de fondo.

## Posicionamiento comparativo

| Dimensión | Holded | Quipu | TrustCore (target) |
|-----------|--------|-------|--------------------|
| Propuesta | Suite de gestión empresarial completa | Facturación + tesorería all-in-one | VeriFactu + Control Horario + IPSI en una suite modular |
| Precio entrada | €/mes multi-tier desde gratuito | €8,50/mes promo → €17 base | €2/usuario/mes (Lite horario) |
| Target principal | Pymes 10-100 empleados | Autónomos + micropymes | Pymes + autónomos + asesorías (Ceuta/Melilla foco diferencial) |
| Trust signals | 2.200 Trustpilot, 80K empresas, video testimoniales, logos cliente, badge VeriFactu | 150+ reviews 5★, testimonios nombrados, colaborador AEAT | 247 facturas enviadas, 0 sanciones, **Pase de Oro Alhambra Venture + #1 CeutaTech Summit** |
| Blog | Hub completo con categorías | Academy + blog | 9 artículos SEO sin hub |
| Demo booking | Formulario + chat + teléfono | Formulario + free trial | Google Calendar directo (infrautilizado) |
| IA / Cloud | Automatización + OCR | Genius AI assistant, OCR | **Asistente virtual + Cloud Computing + Dashboards (no visibles hoy en web)** |

## Patrones a adoptar
1. **Mega-menú de features** por módulo (no solo "productos")
2. **Segmentación por persona**: Autónomos / Pymes / Asesorías con landings dedicadas
3. **Bento grid** para mostrar módulos (VeriFactu, Control Horario, IPSI, Cloud, IA, Dashboards)
4. **Trust bar** con logos cliente + awards inmediatamente bajo el hero
5. **Pricing teaser en home** con link a tabla completa + toggle mensual/anual
6. **Testimonios nombrados** con rol, empresa, métrica concreta
7. **Video o screenshot de dashboard** en hero (no foto stock)
8. **FAQ schema.org** en cada landing para AEO

## Diferenciadores únicos a explotar
- **IPSI para Ceuta/Melilla** — Holded y Quipu no lo tienen integrado nativamente
- **Alhambra Venture + CeutaTech** — ningún competidor tiene awards recientes visibles en web
- **Made in Ceuta** — narrativa local vs. Barcelona/Madrid
- **Modularidad real** — mix-and-match entre TrustinFacts y TrustinTime
- **Cumplimiento 100% + 0 sanciones** — métrica específica y vendible
